# Placitum vlai

[English](README.md) · Русский

Инспектор Placitum на Python. Оценивает серьёзность уязвимости по её русскому описанию.

Не детектор и не поисковик уязвимостей. На вход — уже написанное описание в стиле бюллетеня (ФСТЭК,
BDU), на выход — `score` от 0 до 100. Модель не смотрит код и не ищет SQL-инъекции: только текст.
Решение принимает модуль по порогу маршрута; `deny` сам инспектор не ставит.

```
модуль ──► waf.req.vlai ──► vlai ──► score | allow | error
                              │
                              ├── текст: поле описания в теле или в строке запроса
                              └── модель: ruRoberta-large, классы Low…Critical × уверенность
```

## Модель

[CIRCL/vulnerability-severity-classification-russian-ruRoberta-large](https://huggingface.co/CIRCL/vulnerability-severity-classification-russian-ruRoberta-large),
лицензия CC-BY-4.0. Происхождение, датасет и статья — в [SOURCE](SOURCE).

**Веса в образ не едут.** Процесс берёт их с Hugging Face при первом старте — около 1,4 ГБ — и
кладёт в том `/var/lib/waf/vlai`. Ревизия запинена в `src/classify.py` и совпадает с `SOURCE`:
установка сегодня и через месяц получает одни и те же веса, а подменённая голова репозитория модели
молча к вам не приедет.

На GPU короткий абзац стоит около 20 мс, полное окно в 512 токенов — около 90 мс. На CPU — сотни
миллисекунд, так что для волны в 15–25 мс годится только GPU и короткий текст.

## Как оценивает

Текст берётся из первого места, где он есть: поле `description`, `text`, `advisory`, `details` или
`описание` JSON-тела, сырое тело, те же поля строки запроса. Тело и строку запроса инспектор читает
из обменника по локатору. Текст обрезается до 3072 символов, окно модели — 512 токенов.

Модель возвращает класс и уверенность. Счёт — `100 × вес × уверенность`, веса: Low 0,25, Medium
0,5, High 0,75, Critical 1. Critical с полной уверенностью даёт 100, Low с полной уверенностью — 25.

| Вердикт | Код | Когда |
| --- | --- | --- |
| `score` | `VLAI_SCORE` | модель оценила текст |
| `allow` | `VLAI_NO_TEXT` | текста нет или он короче 4 символов |
| `allow` | `VLAI_SKIPPED` | просьба соседа `skip` сняла проверку |
| `allow` | `VLAI_PROFILE_OFF` | профиль выключен |
| `allow` | `VLAI_OBSERVE` | профиль наблюдает; вердикт, который был бы, — в аудите |
| `error` | `VLAI_STORE_UNAVAILABLE` | обменник не отдал тело или строку запроса |
| `error` | `VLAI_UNKNOWN_PROFILE` | маршрут называет профиль, которого нет в поколении |
| `error` | `VLAI_DEADLINE` | бюджета осталось меньше `VLAI_MIN_BUDGET_MS` |
| `error` | `VLAI_QUEUE_LIMIT` | локальная очередь полна |
| `error` | `VLAI_GEO_UNAVAILABLE` | записи `net`, `net_all` или `asn` нужен кодер гео, а он не отвечает |
| `error` | `VLAI_UNPARSEABLE`, `VLAI_UNSUPPORTED_VERSION`, `VLAI_PHASE_NOT_SUPPORTED`, `VLAI_INTERNAL_ERROR` | битое сообщение, чужая версия схемы, кадр WebSocket, внутренний сбой |

После `error` исход выбирает маршрут: `waf_exception <фаза> inspector pass|deny`. В событии аудита
(`kind=inspector`) — класс, уверенность, счёт по классам, число токенов и была ли обрезка.

## Профили

Профили приезжают от контроллера поколением (ключ `policy/vlai` в `WAF_DESIRED`) и живут только в
памяти. Битое поколение действующее не заменяет и видно как `apply_failed` в кадре присутствия.
Профиль выбирается по `route.profile`; пустой тег означает `default`. Пока поколения нет, работает
встроенный профиль: `enforce`, просьбы `threshold` принимаются от отправителей из `WAF_VLAI_PRIOR`,
поведение при полной очереди — из `queue_full`.

```yaml
mode: enforce                  # печатает контроллер; режим вызова задаётся на маршруте (waf_inspect … mode=)
overload: shed                 # shed | wait: ответить сразу или ждать в полной очереди

trigger:
  prior:                       # чьи просьбы применять; без правила они попадают только в аудит
    - from: ip                 # оба глагола ослабляют проверку, поэтому отправитель всегда по имени
      accept: [threshold, skip]
      codes: [IP_ALLOWLIST]    # пусто — любой повод

outcomes:
  - on: score                  # счёт, который уходит модулю
    at: 60                     # below: true — сравнение в другую сторону, eq: true — ровно
    to: captcha
    do: challenge
    code: VLAI_HOT
  - on: overload               # очередь заполнена не меньше чем на 60% или запрос сброшен
    at: 60                     # 25..100; без него — только сброшенный запрос
    to: counter
    do: note
    apply: ip
    value: 20
    counter: abuse
    code: VLAI_OVERLOAD
  - on: overload
    list: shed_clients         # живой набор
    write: addr                # addr | net | net_all | asn
    ttl: 10m
```

**Режим.** `observe` делает ту же работу (обменник, инференс, коэффициенты соседей), но отдаёт
модулю `allow` с `VLAI_OBSERVE`, а решение оставляет в аудите: `engine.passive: true`,
`would_verdict`, `would_code`, `would_score`. Просьбы и записи в наборы уходят как обычно:
наблюдение глушит только вердикт. `off` отвечает `allow` с `VLAI_PROFILE_OFF` без инференса.

**Просьбы соседей** (`trigger.prior`). Здесь работают два глагола канала действий. `threshold`
умножает отдаваемый модулю счёт на `1 + delta/100` (сумма держится в пределах −100..900; пороги
маршрута не двигаются). `skip` снимает проверку до обменника и инференса и отвечает `allow` с
`VLAI_SKIPPED`; у самого дорогого инспектора это экономит больше всего. Исход каждой просьбы и
значения `score_raw`, `score_scale_percent`, `score_scaled` уходят в событие аудита.

**Строки по исходу** (`outcomes`). `on: score` сравнивает `at` со счётом, который уходит модулю, —
уже после коэффициентов соседей. `on: overload` срабатывает, когда очередь при постановке запроса
заполнена не меньше чем на `at` процентов, и на запросе, сброшенном из-за полной очереди; просьбы
тогда едут в этом ответе `error`. Строка делает одно: `to` с `do` — просьба соседу, `list` с `ttl` —
запись клиента в живой набор. `write` говорит, кого писать: адрес (`addr`, умолчание), его
эффективный анонс (`net`), все анонсы над ним (`net_all`) или автономную систему целиком (`asn`).
Анонсы даёт кодер гео по HTTP (`WAF_VLAI_GEO_URL`) в бюджете сообщения. Запись уходит в keeper
событием `waf.sets.<набор>.event` после ответа.

## Модель без шины

```sh
docker run --rm -v vlai-checkpoint:/var/lib/waf/vlai placitum/vlai \
  classify "Удалённый злоумышленник может выполнить произвольный код."
```

`serve` поднимает HTTP с `POST /classify/severity` — тот же контракт, что у CIRCL ML-Gateway, — на
порту `VLAI_PORT` (по умолчанию 8080).

Что нужно рядом, настройки и первая загрузка модели — в [INSTALL.ru.md](INSTALL.ru.md).
